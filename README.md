# ACE Knowledge Map

山田式ACEメソッド（Athlete Cognitive Education）のインタラクティブ知識マップ。

## 概要

アメーバ状のアニメーションで知識ノード同士の繋がりを有機的に可視化する教材ツール。
6カテゴリの知識を追加・編集・接続し、学習の全体像を直感的に把握できる。

## 6つの知識カテゴリ

1. 脳科学・認知科学
2. 身体性・運動学
3. 心理学・メンタル
4. 戦術・戦略
5. 哲学・思想
6. テクノロジー・AI

## 技術仕様

- HTML/CSS/JavaScript（単一ファイル）
- Canvas APIによるアニメーション描画
- localStorage でデータ保存
- JSON エクスポート/インポート対応

## デプロイ

Netlify経由でホスティング。GitHubへのpushで自動デプロイ。

## ACEメソッドとは

ACE（Athlete Cognitive Education）は、脳科学×アスリート経験×テクノロジーで選手の認知能力を高める教育プログラム。
開発者：山田昌寛（MASA）— セパタクロー日本代表、全日本6連覇。
