# ACE Knowledge Map

山田式ACEメソッド ナレッジマップ — 脳科学×アスリート教育の知識体系を可視化する教材ツール。

## 機能
- アメーバ状アニメーションによる知識ノードの可視化
- ノードの追加・編集・削除（CRUD）
- 6カテゴリ色分け（脳科学/身体/メンタル/ACEメソッド/実例/哲学）
- ノード間の接続管理
- メモ・noteリンクの添付
- データのlocalStorage永続化
- JSON形式のエクスポート/インポート
- 物理演算によるレイアウト自動整理
- モバイルタッチ対応

## デプロイ
Netlifyにて静的ホスティング。
